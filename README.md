## ✧ Sobre a Klein Academy

E se os sonhos fossem tão intensos que pudessem transformar o mundo?

Na história da **Klein Academy**, a sociedade é sustentada por uma camada de sanidade — até que desejos humanos passam a ganhar forma. O ódio, a ganância e o poder deixam de ser apenas sentimentos e ideias.

Em meio a essa mudança, os sonhos de duas crianças ajudam a dar origem à Klein Academy: um espaço para aqueles cujos desejos desafiaram os limites da realidade.

> **Quem diria que a imaginação levava ao infinito? Eles disseram!**

A proposta do RPG se passa na **era atual**, em um mundo que reúne **magia, poderes e monstros**, sem restringir as histórias apenas a esses elementos.

## ⚔️ Por que conhecer este universo?

- **Ambientação fantástica e contemporânea:** um cenário moderno atravessado por acontecimentos extraordinários.
- **Sistema acessível:** a comunidade apresenta seu sistema de RPG como desenvolvido para facilitar a adaptação de participantes.
- **Comunidade acolhedora:** a proposta divulgada é receber bem pessoas novas, sem grupos fechados.
- **Liberdade narrativa:** a fantasia é o ponto de partida, não o limite das possibilidades.

## 💻 Sobre o projeto web

Este repositório reúne os arquivos de um site estático publicado no **GitHub Pages**. O conteúdo pode ser acessado diretamente pelo navegador e a página inicial é `index.html`.

### Estrutura do repositório

```text
KleinAcademy/
├── assets/
├── public/
├── index.html
├── equipe.html
├── mapa.html
├── organizações.html
├── Criaturas Raras.html
└── README.md
```

### Executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/rodriguesssjuliana/KleinAcademy.git
   ```

2. Abra a pasta `KleinAcademy`.
3. Abra `index.html` no navegador. Para recursos que dependam de um servidor local, utilize, por exemplo, a extensão **Live Server** no VS Code.

### Publicação

O site utiliza **GitHub Pages**, configurado para publicar a partir da branch `main` e da pasta `/ (root)`. Após as alterações serem enviadas ao GitHub, uma nova publicação pode ser iniciada automaticamente.
